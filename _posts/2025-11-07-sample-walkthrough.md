This is a sample notebook entry to demonstrate how your Jekyll notebook can host walkthroughs, post‑mortems and explainers.

Use standard Markdown to structure your narrative, embed code snippets and link to external resources.

For example, to embed an image stored in the `assets/images` folder, use the Markdown syntax:

```
![Description of the image](/assets/images/your-image.png)
```

Replace `your-image.png` with the actual file name. The file should be placed in the `assets/images` directory within your repository.

You can also include links to your published stories. For paywalled content, provide a brief summary, a screenshot and a gift link where possible.
